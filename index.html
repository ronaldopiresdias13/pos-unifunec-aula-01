GUIA RÁPIDO

Como usar este laboratório

O catálogo contém comportamentos propositalmente imperfeitos. O objetivo é diagnosticar primeiro e só depois alterar o código.

  • Use Network para observar quando as requisições começam e quanto duram.
  • Use Performance para observar trabalho na main thread e mudanças de layout.
  • Use Lighthouse como triagem, não como resposta final.
